Configuration Warnings

    Editable —

    Locked while trading is armed: Stop Trading → Edit → Save → Start Trading. A buffer edited under a resting order would leave that order enforcing a rule that no longer exists.

    —

    Telegram Notifications

    Notification only. Telegram can never control trading, and there is no inbound path. Toggles apply immediately and are not locked by trading, so a noisy category can be silenced while it is firing.

    Signal visualization only. Not performance. Polymarket settles on a 30-second TWAP. Spot candles cannot reproduce settlement outcomes.
